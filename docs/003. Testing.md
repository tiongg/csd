# Testing

This document covers how to run tests for project. Tests are conducted within Docker containers to ensure consistency across different environments.

## Test Infrastructure

The project uses a dedicated Docker Compose configuration for testing:

- **Database**: PostgreSQL 16 Alpine (isolated test database)
- **Backend**: Java 21 + Maven with Spring Boot test profile

## Running All Tests

To run the complete test suite (backend + database):

```bash
docker compose -f docker-compose.test.yml up --abort-on-container-exit --build
```

This command will:

1. Build the test containers
2. Set up a fresh PostgreSQL database
3. Run Flyway migrations
4. Execute backend tests
5. Stop and remove containers after completion

## Backend Tests

Backend tests are written using JUnit 5 and Spring Boot Test framework.

### Run Backend Tests Only

```bash
docker compose -f docker-compose.test.yml up backend --build
```

### Run Specific Test Class

```bash
docker compose -f docker-compose.test.yml run backend mvn test -Dtest=AuthServiceTest
```

### Test Coverage

Backend tests cover:

- Authentication & Authorization (JWT, OAuth2)
- User management (Admin, Contributor, Learner)
- Course management
- Team management
- Glossary functionality
- Analytics services
- AI integration
- Tag management
- Notification system

### Test Locations

- **Test classes**: `backend/src/test/java/csd/t6/backend/`
- **Test resources**: `backend/src/test/resources/`

## Test Database

The test environment uses an isolated PostgreSQL database:

- **Container name**: `db-test`
- **Database**: `postgres`
- **User**: `postgres`
- **Password**: `password`

The database is freshly created for each test run, ensuring test isolation.

## CI/CD Integration

Tests are automatically run in CI/CD pipelines:

- On pull requests
- Before merging to main branches
- During deployment processes

## Troubleshooting

### Backend Tests Fail with Database Connection

Ensure the test database is healthy:

```bash
docker compose -f docker-compose.test.yml up db flyway -d
docker compose -f docker-compose.test.yml logs -f db
```

### Slow Test Performance

Test performance can be affected by:

- First-time Maven dependency downloads
- Docker image building
- Database migration execution

Subsequent runs will be faster due to Docker layer caching and Maven dependency caching.
