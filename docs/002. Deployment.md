# Deployment

Both Frontend and Backend are deployed automatically using CI/CD pipelines. The frontend is hosted on Cloudflare Pages, while the backend and Y.js WebSocket server are deployed on Fly.io.

## Production Environment

The Six Seven is deployed across multiple cloud platforms:

- **Frontend**: [Cloudflare Pages](https://www.cloudflare.com/)
- **Backend API**: [Fly.io](https://fly.io/)
- **Y.js WebSocket Server**: [Fly.io](https://fly.io/)

The deployed version can be viewed [here](https://sixsevennn.pages.dev/)

## Frontend Deployment (Cloudflare Pages)

The frontend is automatically deployed to Cloudflare Pages. Changes pushed to the frontend repository trigger automatic builds and deployments.

### Configuration

- **Build Command**: `npm run build`
- **Build Output**: `dist/`
- **Node.js Version**: 21+
- **Environment Variables**: Set via Cloudflare Pages dashboard

## Backend Deployment (Fly.io)

The Spring Boot backend and Y.js WebSocket server are deployed on Fly.io using Docker containers.

### Infrastructure

- **Java Runtime**: Java 21+
- **Database**: Managed PostgreSQL on Fly.io
- **Storage**: Managed MinIO/S3-compatible storage
- **Health Checks**: Configured for automatic monitoring
